# Contributing

Burnout Mashup is an unofficial, experimental fork (see README.md). Thank you for helping.

## Rules
- **No game material.** Do not contribute game data, retail assets, extracted or retail-derived output, executables, translated
  game code or generated game-code files (anything the recompiler produces from the game). Do not paste generated code into
  issues or pull requests. Hook marks stay address anchors plus your own text.
- Licences: **inbound = outbound**. Code, SDK and tools are MIT; documentation CC-BY-4.0; original example assets CC0-1.0
  (only if you have the authority to dedicate them); material that comes from elsewhere keeps its own licence and must say so.
- **Disclose AI assistance** in the pull request description (which tool, which parts).
- Tests are required for code changes (the tool suites and host unit tests run without the game). Keep Windows x64 as the scope.
- Problems of the Takedawn project itself go upstream, and only when reproducible there. Burnout Mashup problems do not.
