# Burnout Mashup

Burnout Mashup is an unofficial fan project for **Burnout 3: Takedown** on PC: more rivals than the game's 6 cars, bigger
pile-ups, an options pack (Burnout 2 boost, car colour picker, demo crash physics and more), mod support and a Workbench for
tracks and cars. It is not affiliated with, authorised by or endorsed by Electronic Arts, Criterion Games, Microsoft or the
Takedawn project. "Burnout" is a trademark of its owner.

This repository holds the **releases** only. Development happens elsewhere.

## Download
Get the latest version from the [Releases page](https://github.com/HeartWorthBreaking/burnout-mashup/releases/latest):
- `BurnoutMashup-<version>-windows-first-install.zip` - for a new install (Python included).
- `BurnoutMashup-<version>-windows.zip` - the update package (the launcher's Help -> **Check for updates...** uses it).

Unpack it into a new folder of its own and start `Burnout Mashup.exe`.

## What you need
- Windows 10 or 11 (64-bit).
- **Your own copy of Burnout 3: Takedown** for the original Xbox, North American (NTSC-U) version.

There is no game in this repository or in a release: no game data, no game files and no game executable. On the Setup tab, drop
your game folder on the launcher window and press **Build Mashup**: the launcher builds the game on your PC from your own copy.
After every update, run **Build Mashup** again if it does not start by itself; new features and options work only after it has
finished.

## Updates
Updates are signed. The launcher checks this repository's latest release only when you ask (Help -> **Check for updates...**)
and installs a release only if its signature matches the project's key.

## Reporting problems
Please open an [issue](https://github.com/HeartWorthBreaking/burnout-mashup/issues/new/choose) and attach the diagnostic export
the issue form asks for. Never attach game files or anything built from your game data. Security problems: please use a private
security advisory on this repository.
