# assets/icon/bmashup.ico - the Burnout Mashup icon (since 0.2.0-alpha.3)

Provenance: ORIGINAL art for Burnout Mashup: the letters BM in red chrome on a dark steel rounded tile with an arc; sizes 256, 64, 48,
40, 32, 24, 20, 16. A rendered picture, made once with a maintainer's script: the lettering is fixed artwork made from a commercial
font (Kenyan Coffee, Typodermic) whose font software is not part of this repository. No game art and no upstream (Takedawn) art.
`make_bmashup_ico.py` beside this file writes the EARLIER icon (a blue tile with two white chevrons, up to 0.2.0-alpha.2); it does
not make this icon and the build does not use it.
The upstream icon files (takedawn*.svg) stay in this folder for the upstream build (BMASHUP_IDENTITY=OFF / BO3_RELEASE) only.
