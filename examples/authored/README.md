# AUTHORED examples (mod kit 0.4.0) - original sources only

Every file here is original: written by the Burnout Mashup workers or generated by code in this kit. No retail or Revenge file,
no file derived from one, no binary program. `AUTHORED_FILES.json` lists every non-text file with its sha256 and where it was
made; the kit's release check compares each with its original and regenerates the generated ones byte for byte
(`AUTHORED_FILES.json` lists every non-text file with its sha256).

| folder | what | regenerate / build | needs your game data for |
|---|---|---|---|
| `carimport\coupe`, `carimport\wedge` | glTF 2.0 test cars (`.gltf` + `.bin`), texture / paint-mask PNGs, `car.toml` | `py -3 -B tools\carimport\carimport.py demo coupe <dir>` writes them again (byte-identical) | `carimport.py build / package` (donor parts: COMPCAR1) |
| `trackbuild` | package descriptions of BM Test Loop and the canyon stadium | sources: `py -3 -B tools\trackbuild\tb.py gen-testloop <dir> [--variant canyon]` | `tb.py build` (donor: Gamedata header, enviro, audio of EU/M1_V1) |
| `fetex-art` | `gen_art.py` (OCEANIA map art, marker, a garage photo: every pixel computed) + the two packs' mod.toml | `py -3 -B gen_art.py <dir>` then `fetex.py pack <dir>\photo.json ...` | nothing (the OCEANIA pack requires the wt4 region mod: `examples\content\wt-region`) |
| `veh-series` | `make_veh_packs.py`: Neon, Dust Runners, retail-car paints, a cross-mod paint (+ fixtures, negatives) | `py -3 -B make_veh_packs.py <new dir>` (uses `tools\vehtool`) | nothing (cars use `model = donor`) |
| `bm-coupes` | p4.3's combined example: series "BM Coupes" (mod.toml) + the coupe's garage photo (6 small PNGs + spec) | `fetex.py pack photo_spec.json art\photo.txd`; the model: `carimport.py package` of the coupe, files renamed to `pveh\BMCO\CIC1.*` | the coupe model's donor parts |

Install what you build into a content mods folder; the car / track packages contain donor parts and stay LOCAL ONLY.
