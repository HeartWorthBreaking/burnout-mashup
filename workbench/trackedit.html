Track editor - first slice

Not a complete editor. Source = the project's track description, OBJ and textures; game files come only from Build. Drag: orbit, right-drag / shift-drag: pan, wheel: zoom, W A S D Q E: fly, click: select (a start object, unit, corner, or a face group of the mesh).

Layers

Shading is APPROXIMATE: texture x baked vertex colour only. No sky, fog or track lighting (enviro.dat has no verified reader; the build copies the donor's unchanged).

Orange = open edges (one face; uv / colour seams closed by position are not open). Green = gap distances of the candidates / the previewed pairs, pink = chosen vertices, blue = faces the weld stretches. A weld moves corners only (uv / normal / colour references kept); ambiguous matches, gaps wider than the tolerance, collapsed / flipped faces and non-manifold results are refused. Gaps are never filled automatically.

The winding of the new faces follows both neighbours (this fixes the correspondence); existing material; uv: u along chain A, v across (4 m per texture repeat); one new normal per face.
