# `[bmashup.music] version 1` - music packs as data mods (EA GAMES TRAX + the track banner)

Platform table `music` 1 (p4.1). No code, no approval. Example: `sdk\examples\music-pack` (two mods: `gp.music.tones` and
`gp.music.tones-remix`; the tones are generated by `make_tones.py`, original synthetic sine tones - no recorded audio).

## Declaration
```toml
[bmashup]
requires = ["bmashup.music>=1"]          # the table version (an older host refuses this mod alone)

[bmashup.music]
version = 1
soundtrack = "BM Test Tones"
add = ["a440 = music/tone_440.wav | Tone 1 - 440 Hz | BM Test Lab | Synthetic Tones"]
#      <entry id> = <file in the mod> | <title> | <artist> [| <album>]
replace = ["gp.music.tones/b1000 = music/tone_523.wav | Tone 3 - 523 Hz | BM Remix | Synthetic Tones"]
#      <mod id>/<entry id> = ...   - the other mod must be in [bmashup] requires_mods
```
- Each admitted music mod is one soundtrack in the title's EA GAMES TRAX list; custom music at start switches the first music
  start to it. Files go through the upstream custom-music path (host decoder: wav / mp3 / flac / ogg).
- Banner: when a mod song starts, its title / artist / album are shown in the title's own EA GAMES TRAX pop-up for 5 s
  (artist first line, title second, album third). The title's own 44 EA TRAX songs are not touched.
- The player's own music folder (`audio.custom_music_dir`) wins over mod music (logged).
- Staging (p4.1): the host copies the music into a cache folder, never into the saves: `BMASHUP_MUSIC_CACHE` >
  `%LOCALAPPDATA%\BurnoutMashup\music-cache` > `$XDG_CACHE_HOME/burnoutmashup/music-cache` > `$HOME/.cache/...`, one
  `set-<16 hex>` folder per set of music. **Nothing is ever deleted**: old `set-*` folders stay until you delete the cache
  folder (safe at any time).

## Bounds and conflicts
16 soundtracks, 64 entries a mod, 256 tracks, 64 MiB a file, 512 MiB in all; ids / titles / artist / album: limited charset,
up to 31 characters. Refused whole (the later mod, by the admission): a soundtrack name already used (case-insensitive),
capacity, a replace of nothing / already replaced / a title clash, a replace target not in `requires_mods`, an invalid
declaration. A file problem at staging drops that mod's music (logged ERROR); a dropped replacer restores the original.
Limitation: the list orders a soundtrack's songs by the natural order of their titles; an mp3 / flac / ogg title tag names
it in the list, the banner always shows the declared texts.
