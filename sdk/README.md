# bmashup-sdk 0.4.2 - Burnout Mashup modding SDK (EXPERIMENTAL Windows x64, local, not published)

One host exe, many drop-in mods. The headers, helper and examples a mod author needs for native plugins and data-only mods
of the Burnout Mashup build of Takedawn (Burnout 3 native PC), verified offline against the reference host **p4.2**
`burnout3_gp_p4_2.exe` (Burnout Mashup **platform 0.1.5**, sha256 `4fd86d1066ae...`, build identity
`bmp-0.1.5+0db09076e5b8`; an integration candidate, not a frozen host). **Windows x64 only** is built and tested. Part of the
local mod kit `bmashup-modkit-0.3.1`. SDK package 0.4.2, kit 0.3.1 and platform 0.1.5 are separate version domains (the
kit's `docs\VERSIONING.md`).

The Burnout Mashup services (`bmashup.*`) are private and experimental: offered only by Burnout Mashup builds; they may
change or go away (each header says so). `takedawn.race` and the plugin API are Takedawn's.

built (`EXPECTED_BUILD_SHA256.txt` says what a correct build gives with the kit's toolchain).

## A plugin in five lines
A plugin is a DLL (`.asi`) in a mod folder whose `mod.toml` has `[plugin] api = 1, windows = "x.asi"`. It exports
`takedawn_plugin_api_version` and `takedawn_plugin_init` (and optionally `takedawn_plugin_service` /
`takedawn_plugin_services_done`); the host offers each service once after init (bmashup.host first) and the plugin keeps the
tables it needs (`bmsdk_offer`, `bmsdk_need`). The examples show the pattern; `docs\MODDING_GUIDE.md` of the kit explains it.

## Status of what the examples use (details: the kit's `docs\services\`)
RUNTIME-VALIDATED on p4 / p4.1 / p4.2 or their slice builds: autopilot 2 (engage per race, after a race exit, release),
vphysics query + Drag + the top-speed limit, traffic density 0.0..2.0, AI pace 0.5..1.5, settings + camera FOV (4:3),
CRASH_RESULT (crash1 build, p4.1), AI Top speed and a signed value, music packs. The modules this kit builds were NOT launched: the runs used modules built from the
same sources in the workspace with other flags (different bytes). Of the eight (a)-(h) plugin modules, six are byte-identical
to kit 0.2.1's prebuilt modules (start-up runtime-validated on p3, boot-only launch bmp_kit2_1); host-info and events-observer
have new bytes (built against the 0.4.x headers). On p4.2 (gp_p42_5) kit 0.2.1's prebuilt events-observer module bound `bmashup.events` 6.
